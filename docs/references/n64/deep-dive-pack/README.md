# N64 Video Core Deep Dive Pack

This pack is intended for an engineer (or automated agent) working on a Nintendo 64 **video core** implementation, typically meaning **RDP + VI** behavior (and the related RDRAM/MI glue required for correctness).

## Contents

- `report.md` / `report.pdf` — main research report
- `docs/links/curated_links.md` — high-signal reading list (online)
- `docs/extracted/` — selected upstream reference files (READMEs, licenses, and a few headers)
- `docs/extracted/cheatsheets/` — quick-reference tables and checklists

## Notes on licensing

- Files under `docs/extracted/` come from upstream open-source repos and retain their original license terms.
- This pack does **not** include full copies of proprietary SDK manuals; instead, those are referenced via URLs in `docs/links/curated_links.md`.
